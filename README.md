## 🪞 Design Scope

Your ID card must include the following key elements:

### ✅ Front Side

* Organization Name & Logo
* Full Name of the Person
* Profile Photo
* Designation / Role
* ID Number or Barcode (Optional)

### ✅ Back Side (Optional but recommended)

* Contact Info (Email / Phone)
* Emergency Contact
* Validity or Issue/Expiry Dates
* Terms or Instructions (Optional)
* Signature / QR Code (Bonus)

---

## 🎨 CSS Styling Guidelines

Use modern CSS to ensure your ID card is **visually professional and print-ready**.

### 🎯 Goals per Section:

#### ✅ Background & Layout

* Use colors or background images tastefully
* Maintain real-world ID size: `85mm x 55mm` or `90mm x 60mm`

#### ✅ Typography

* Use legible fonts with proper spacing
* Show hierarchy (Name > Title > Info)

#### ✅ Styling & Effects

* Add shadows, border radius, rounded profile photo, and alignment
* Try **hover effects**, **barcode styling**, or **card flip** (bonus)

#### ✅ Print Optimization

* Use `@media print` in CSS
* Ensure ID card is printable at actual size

---

## 🧪 CSS Property Checklist

Try to incorporate the following:

* **Typography:**
  `font-family`, `font-size`, `text-transform`, `letter-spacing`, `line-height`

* **Layout & Sizing:**
  `display`, `flex`, `grid`, `padding`, `margin`, `width`, `height`

* **Design Elements:**
  `border-radius`, `box-shadow`, `background`, `gradient`, `transform`, `transition`, `hover`

* **Extras (Bonus):**
  `@media print`, `barcode`, `QR code`, `flip animation`, `profile image border`
